# FLOWCO_CRFTCARD — CR Card Cleaner

เครื่องมือเว็บสำหรับแปลงรายงาน **บัตรเครดิต** และ **บัตรฟลีทการ์ด** (ไฟล์ .xls / .xlsx ที่ออกจากระบบเป็นแบบใบปะหน้า) ให้เป็นตารางรายการพร้อมจัดกลุ่ม สรุปยอด และแยกชีตตามกะ

พัฒนาต่อจากมาโคร Excel เดิม (`data_crcard_tool.xltm`) — โค้ดต้นฉบับเก็บไว้ที่ `docs/original-macro-Module1.bas`

## วิธีใช้

1. เปิด `index.html` ด้วย Chrome หรือ Edge (ดับเบิลคลิกได้เลย หรือเปิดผ่าน GitHub Pages)
2. เลือกไฟล์รายงาน → เลือกชีต → กด **ประมวลผล**
3. ตรวจผลในตารางพรีวิว (สลับแท็บดูแต่ละชีตได้) แล้วกด **ดาวน์โหลด .xlsx**

ไฟล์ถูกประมวลผลในเบราว์เซอร์ของเครื่องผู้ใช้เท่านั้น ไม่มีการอัปโหลดข้อมูลไปที่ใด
ต้องต่ออินเทอร์เน็ตตอนเปิดหน้า เพื่อโหลดไลบรารี SheetJS และ JSZip จาก cdnjs.cloudflare.com

## กติกาการประมวลผล

**ขั้นตอนร่วม**
- ตรวจประเภทรายงานจากคำแรกที่เจอ: `รายงานบัตรเครดิต` หรือ `รายงานบัตรฟลีทการ์ด`
- คัดแถวที่คอลัมน์ D เป็นตัวเลข (รองรับเซลล์ merge) แล้วดึงคอลัมน์ D–AQ
- ลบแถวว่าง และแทรกหัวคอลัมน์
- อ่านรหัสกะจากป้าย `รหัสกะ :` (ฟลีท: P→R, เครดิต: O→Q) ใช้กับทุกรายการจนกว่าจะเจอรหัสใหม่ แล้วเพิ่มเป็นคอลัมน์ E
- หมายเลขบัตรที่ถูกตัดข้ามหน้าจะถูกต่อกลับเป็นรายการเดียว: ถ้าข้อความบัตรจบด้วย `/` หรือไม่มีตัวเลขเลย (เช่น `KTB PTT Co-brand/ `, `แลกคะแนน `, `BCP `) จะหยิบชิ้นที่หลุด ซึ่งอยู่โดดๆ ในคอลัมน์หมายเลขบัตรก่อนถึงรายการถัดไป มาต่อท้าย

**รายงานบัตรฟลีทการ์ด**
- ย้ายคอลัมน์ E→A (หัวชื่อ `ใบกำกับภาษีอย่างย่อ`), K→B, U→C, AN→D และลบแถวที่ A ว่าง
- แบ่งกลุ่มตามเลข 4 หลักแรกหลัง `/` ในหมายเลขบัตร

**รายงานบัตรเครดิต**
- ย้ายคอลัมน์ E→A, I→B, T→C, AL→D และลบรายการที่ยอดเงินเป็น 0.00 / -0.00
- กลุ่ม: 1) AIS 2) บัตรเครดิต (XXXXXX) — ถ้าเลขที่ใบเสร็จเป็นตัวเลขล้วน (เช่น `01261000265`) แยกเป็นกลุ่ม **ลูกหนี้ชำระเงิน** ต่อจากกลุ่มบัตรเครดิต 3) QR Payment 4) KPLUS&PROM (KPLUS ก่อน แล้ว PROMPTPAY แล้ว BCP GreenMiles/) 5) แลกคะแนน 6) อื่นๆ

**ผลลัพธ์**
- รหัสกะเป็นระดับใหญ่สุด: กะ → กลุ่ม → รายการ
- ในกลุ่มเรียงตาม ชื่อบัตรหน้า `/` → ชุดตัวเลขหลัง `/`
- ทุกกลุ่มมีหัวคอลัมน์ ท้ายกลุ่มมียอดรวมตัวหนา และเว้น 3 บรรทัดก่อนกลุ่มใหม่
- ไฟล์ Excel มีชีต `shift_all` (รวมทุกกะ) และ `shift_<รหัสกะ>` แยกทีละกะ
- ชื่อไฟล์: `Cleaned_Upload_YYYYMMDD_HHMMSS.xlsx`
